## 一、运行方式 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

在本目录的 PowerShell 终端执行：

```powershell
& '.\【Windows】验证网页菜单.ps1'
```

阅读自述后回车，其他输入取消；自动化须显式传 `-Run`：

```powershell
& '.\【Windows】验证网页菜单.ps1' -Run
```

入口从自身位置定位[真实部署脚本](../../../../部署/Windows/Deployment/【Windows】部署.ps1/【Windows】部署.ps1)。支持 Windows PowerShell 5.1；也可用现有 PowerShell 7 在其他系统进行隔离检查。先解析并编译进程管理器类型，再点载真实函数；点载不会执行部署入口。

## 二、验证范围 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- 实际公网地址和本机地址映射、连续选择，以及服务器模式只列本机地址。
- 默认浏览器打开失败后仍可继续选择，服务状态不变。
- Esc、空选、收起项、非法结果和选择器错误均不打开网页，保留服务并进入可恢复的收起状态。
- 菜单等待期间后端或隧道退出，保留原退出状态并清理本次菜单与服务；Ctrl+C的明确取消结果进入清理。
- PowerShell AST解析和内置C#进程管理器编译；测试不实例化Windows Job Object。

假会话、假fzf结果和假浏览器只在系统临时目录写夹具，不下载、不联网、不打开真实浏览器，也不启动后端／隧道。服务和菜单进程均为状态替身；不能据此声称 Windows 实机的控制台、Job Object、ACL、浏览器或公网已验收。
