## <span id="jobs-toc-heading-1" data-jobs-toc="v2">一、运行方式 <a href="#前言">🔼</a> <a href="#🔚">🔽</a></span><!-- jobs-toc:heading-end -->

在本文所在目录执行：

```zsh
/bin/zsh './【MacOS】验证工作台构建.command'
```

阅读自述后回车开始，输入其它文字取消。自动化运行须显式传入 `--run`：

```zsh
/bin/zsh './【MacOS】验证工作台构建.command' --run
```

脚本从自身位置定位[部署入口](../../../../部署/MacOS/Deployment/【MacOS】启动维修工作台.command/【MacOS】启动维修工作台.command)，支持从其它工作目录运行。需要系统自带的 [**zsh**](https://www.zsh.org/)、`sed`、`grep`、`tee`、`cmp` 等基础命令，不需要安装 [**Go**](https://go.dev/)、fzf 或隧道工具。

## <span id="jobs-toc-heading-2" data-jobs-toc="v2">二、验证范围 <a href="#前言">🔼</a> <a href="#🔚">🔽</a></span><!-- jobs-toc:heading-end -->

- 未自定义模块源时，构建子进程采用镜像、官方源、源码直取的顺序。
- 保留进程显式自定义、空值、`off`；保留用户配置文件中的自定义、默认或空值；`GOENV=off` 与其它有效下载策略分别验证。
- 模块校验和私库相关环境保持原值，构建结束后调用层的 `GOPROXY` 不变。
- 成功构建才替换运行产物；构建失败传播真实退出码，缺少新可执行文件时拒绝替换旧产物。
- 假构建的标准输出、标准错误同步出现在终端和日志中；使用中文、空格夹具目录验证构建定位。
- 假后端和假 `curl` 核对 `/api/v38/healthz` 健康接口；测试不监听真实端口，结束时回收本组睡眠进程。
- 验证运行态初始化返回时不会提前清理子进程；正常退出、受控失败、仅向父 Shell 发送 `TERM` 时，实际退出陷阱都会回收本组睡眠进程，并保留对应退出码。
- 网页菜单将公网地址和本机地址交给假 `open`，核对实际传入的 URL；连续选择和首次打开失败后仍能重选，服务器模式只显示本机地址。
- Esc、空选或“收起菜单”不会打开网页，也不会停止后端和隧道；菜单等待中后端或隧道退出，以及菜单 `Ctrl+C`、仅向父 Shell 发送 `TERM`，均核对退出码和菜单／服务进程回收。

测试只复制部署函数到临时文件，移除唯一的 `main "$@"` 调用后加载。结构不符合预期时停止，避免误执行部署。真实构建函数使用假 Go 替身；网页菜单使用函数形式的假 fzf／open，假服务为真实睡眠子进程。测试进程使用固定基础命令 PATH 和无用户启动配置的解释器，保证夹具可复跑。

本组用替身隔离原点清单采集，保留真实菜单 PID、父进程 `TERM` 和子进程回收断言；原点、真实 `ps` 身份与 PID 复用保护由[配对反部署回归](../../反部署/验证反部署.mjs/README.md)独立核验。测试不下载依赖、不调用真实后端、不建立公网连接或打开真实浏览器，不写入项目运行目录或公共工具缓存。

## <span id="jobs-toc-heading-3" data-jobs-toc="v2">三、日志与结果 <a href="#前言">🔼</a> <a href="#🔚">🔽</a></span><!-- jobs-toc:heading-end -->

开始时显示系统临时目录中的 `repair-build-check.*` 位置。成功返回 `0` 并清理夹具；失败返回 `1`，保留 `suite.log`、每组 `console.log`、构建日志、假 Go 捕获结果、菜单选项与假浏览器 URL，便于核对。`Ctrl+C` 返回 `130`，回收当前菜单夹具进程并保留已生成诊断。

这是构建与交互流程隔离回归，不替代真实依赖下载、后端构建、公网隧道、默认浏览器或目标机器部署验收。

**终端配色保护：** 独立运行时，在支持完整保存与恢复配色的交互终端中临时使用黑底白字及统一强调色；正常结束、失败或可捕获中断后恢复进入前的配色，不修改终端全局偏好或 Shell 启动配置。不支持完整保护、无交互终端、`NO_COLOR`、既有纯文本模式和 Sourcetree 场景不切换配色，并沿用纯文本输出约定。强制终止（如 `kill -9`）无法由脚本自身保证恢复，请使用运行时显示的独立恢复入口。
