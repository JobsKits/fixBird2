浏览器维修协同工作台调用 `/api/v38`，提供完整业务操作和独立合成演示。

页面同时支持桌面与手机竖屏。600px 及以下使用顶部横向滑动导航、工单字段卡片、全屏详情和单列表单；输入字号16px、触控关闭按钮44px，并预留设备安全区。语言、主题、筛选、工作日志及全部业务入口保留。原生桌面另见 [PC 端导航](../README.md)，当前截图与验证边界见[客户端资产盘点](../../../../项目相关报告/README.md#web-portrait)。

## <span id="jobs-toc-heading-1" data-jobs-toc="v2">一、启动与演示 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

运行 [MacOS 部署入口](../../../../部署/MacOS/Deployment/【MacOS】启动维修工作台.command/【MacOS】启动维修工作台.command) 后访问 [维修工作台](http://127.0.0.1:8098/)；[Web 管理端](http://127.0.0.1:8098/admin/)使用独立界面。

无服务器时，在本目录使用 [**Node.js**](https://nodejs.org/) 运行：

```sh
node './离线预览.mjs'
```

访问 [离线工作台](http://127.0.0.1:8099/) 或 [离线管理端](http://127.0.0.1:8099/admin/)；服务只托管静态界面，API 返回 503，不读取真实业务存储。页面继续请求 API，失败后显示独立合成数据；动态列表提供空态与重载，本地 Logo 可离线显示。

四张经营概览卡可直接进入对应工作范围：进行中工单排除已完结，结算待办理与待完结确认切换到对应工单筛选，客户待收款进入“现金与票据”的待收款范围，可用“重置”恢复全部票款。概览入口会清除旧搜索和筛选，避免与卡片的全范围指标混用。

工单五个筛选标题分别显示数量；数量覆盖当前身份及搜索、阶段、资料、回款条件下的全部授权结果，当前页和选中的筛选按钮不截断其它类别数量。新后端通过分页响应一次返回五类 `counts`，旧服务缺少该字段时并发读取各筛选的精确 `total`；加载显示 `（…）`，失败显示 `（—）`，重新加载可重试。演示数量只来自独立合成台账。`status=active` 的进行中集合需要使用当前后端构建；正在运行的旧二进制须重新启动部署才能载入该筛选。

左侧导航悬停时可播放本机合成的四次短木质敲击，无需下载音频。按 [Chrome 自动播放策略](https://developer.chrome.com/blog/autoplay)，先在页面点击或使用键盘，之后悬停才可播放；移动触摸不触发悬停音效。侧栏底部的“导航音效”可随时关闭，窄屏显示为顶栏声音按钮；只在本机保存开关偏好。音效有节流且不叠响，页面隐藏或离开立即停止，浏览器不支持或拒绝音频时仍可正常导航。

## <span id="jobs-toc-heading-2" data-jobs-toc="v2">二、个人工作日志与事件提醒 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

“工作日志”默认打开今天，可切换上／下月、选择历史或未来日期记录，按“今天”回到当日。日期切换保留当前账号内存草稿；“放弃草稿并重新加载”才明确丢弃该日期未保存内容。普通账号只看本人，管理员可通过“查看账户”只读查看他人；查看他人日志不会取得其提醒权限。

日历下方的“全部日志”跨月份分页，点击记录可回到对应日期查看详情。本人可确认删除该日期日志及附件，管理员查看他人时不提供删除操作。今日新草稿显示当前编辑时刻，已保存记录显示最近保存时间，均精确到秒。宽屏日历与编辑卡片自然等高，窄屏优先显示编辑区。

正文作为纯文本保存。本地选择和剪贴板文件共用图片／视频路径，支持 PNG、JPEG、GIF、WebP、MP4、WebM、QuickTime；默认单图8 MiB、单视频16 MiB，每日日志最多8个附件且合计32 MiB，正文最多20000字符。附件通过受保护 API 读取后生成当前会话的 Blob 预览和下载，不使用公开原件地址；视频能否播放仍取决于浏览器及文件编码。上传附件后继续保存正文；上传返回不会覆盖未保存文字。

“我的待办”内可新建事件提醒，也可从工单待办的“设置提醒”预填标题。时间面板可选择日期、小时与分钟，“确认时间”回填表单，“取消”保留原时间；再按“保存提醒”由后端保存 UTC 时刻及 IANA 时区，支持修改、完成与取消。页面可见时约15秒检查到期提醒，恢复可见或网络恢复后补检；服务器原子认领后在右下角显示非抢焦点 tips。“关闭提醒”只隐藏提示，“标为完成”才明确更新状态；多标签页、刷新和重开不重复认领同一版本。页面关闭、离线或休眠时不承诺系统推送或可靠送达，App 顶部提醒属于后续范围。

真实 API 失败保留当前账号内存草稿，不写入浏览器持久缓存、不复制到独立演示，也不显示保存成功。结果未知时先重新读取核对；提醒仍未确认时只能显式重试原路径、原正文，复用既有请求键。版本冲突不静默覆盖其它设备修改；身份切换、退出或会话失效会清理上一账号草稿、预览 Blob 和迟到请求。独立演示仅保存合成账号内存数据并明确标识。新接口需要当前后端构建，旧运行二进制须重新部署才能保存。

## 三、<span id="inventory-purchase-usage">库存明细与采购附件</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

“库存与借还”的配件卡片可点击或用键盘进入 SKU、可用／隔离数量及当前授权的关联借还、采购明细。采购卡片的“查看采购明细”显示供应商、收货情况和私有附件；内部角色与供应商读取权限沿[接口合同](../../../后端/README.md#inventory-purchase-contract)，卡片入口不扩大授权。

管理员／仓库／调度在“采购登记”中可从本地选择一个图片或文件，也可主动粘贴剪贴板中的图片，确认采购时一起保存；已登记采购可在明细点“添加采购附件”后确认追加。支持 PNG／JPEG／GIF／WebP、PDF、TXT／CSV、DOCX／XLSX／PPTX；单文件8 MiB、每单8件且合计32 MiB，实际内容仍由服务端校验。附件卡片显示名称、类型与大小，图片经鉴权后预览，其他文件明确下载，不内联执行文档。

读取原件使用当前会话，关闭或替换明细、切换账号会释放预览并阻止旧响应重开弹窗；写失败或未知结果保留文件与表单，原请求键用于显式重试，不把真实采购／文件自动复制到演示。独立演示附件只留合成内存副本，刷新不保留。新接口与去原件视图需重部署当前后端构建后使用。
