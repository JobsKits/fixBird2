## 🔥 <span id="前言">前言</span>

本目录是本期独立交付的[**微信小程序**](https://developers.weixin.qq.com/miniprogram/dev/framework/)官方原生工程，采用JavaScript、WXML、WXSS与JSON，调用现有V3.8服务；不是H5嵌入页面。

## 一、<span id="status">当前状态</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

1、安装[**微信开发者工具**](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，选择“导入项目”，目录选择本目录 `代码/前端/微信小程序`。配置自有AppID；随包 `touristappid` 只作开发者工具本地体验。

2、点击“编译”，使用 `customer` 与合成密码 `Demo-Repair-2026!` 登录；服务器未启动时进入独立合成演示。示例角色按钮可选择其它岗位，密码需自行填写。

3、在“我的”填写服务端根地址，不加 `/api/v38`，保存后重新登录。电脑开发工具可使用 `http://127.0.0.1:8098`；仅本地调试时在开发工具中临时关闭合法域名校验，发布配置仍保留校验。

4、手机无法用电脑回环地址访问服务。使用已验证的可信HTTPS地址并配置小程序request／downloadFile合法域名；穿透随机地址不自动具备备案、平台配置或正式发布条件。部署入口见[部署说明](../../../部署/README.md#local-tunnel)。公开访问只使用合成数据，不能将现有演示身份当成正式身份。

5、开发者工具预览、手机扫码、体验版本、提审与正式发布分别验收；当前没有上传、提审或正式发布。

## 三、<span id="features">页面与业务范围</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

| 页面 | 当前能力 |
| --- | --- |
| 登录与我的 | 十语与三态外观；使用现有平台账号，选择示例角色，配置服务器根地址与500—10000毫秒超时，退出清理内存会话 |
| 工单 | 首页概览、服务端搜索／阶段筛选／30条分页、新建寄修／上门／销售、完整空态与重新加载 |
| 完整详情 | 工单、报价与先款约定、收退款、发票、异议、余项、事件与验收历史；原件按当前授权下载 |
| 当前可办理 | 服务端 `allowedActions` 决定可见动作；复用共享43类合同表单，金额转整数分，Canvas实际手写PNG签名 |
| 附件 | 从微信会话选择≤6MB文件并编码提交；原件鉴权下载后调用微信文件或图片预览；文件内容只留逻辑层，不经视图数据传输 |
| 库存借还 | 库存、借还与采购列表及重载，连接服务端办理借用、归还、耗用、处置、转跟踪和采购收货；权限及数量由服务端裁决 |

“我的”或登录页齿轮进入设置，语言和外观选择器即时切换界面。语言提供简体中文、繁体中文、藏文、英文、日文、法文、西班牙文、德文、俄文与韩文；主题提供白天、黑夜与跟随系统，选择保存在本机偏好中。业务名称、客户输入和服务端业务正文保持原值。界面文案以[共享语言目录](../共享组件/Resources/ui-l10n.json)为源，打包资源随应用离线读取。

服务端真实业务与其它客户端使用同一份 `/api/v38`。小程序不提供后台账号启停、安全审计和全量导出页面；这些入口继续使用管理端。现金人工登记不等于微信支付，手写签名不等于认证电子签。微信身份登录、微信支付、订阅消息、地图、实时物流、IM和AI尚未接入。

## 四、<span id="fallback">网络、未知提交与离线演示</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

每次进入、刷新、搜索、翻页和写入均请求API，默认超时2200毫秒。读取失败后清理服务端视图，显示独立合成资料；后续有效响应自动恢复。合成示例账号离线登录会在刷新时重试相同合成身份，服务器恢复后自动采用服务端资料，不上传本地演示操作。账号或地址切换、当前401会撤销会话并清空旧私有视图；迟到响应不能覆盖新页面或新身份。

真实账号已认证而读取失败时，演示视图只供查看，办理入口关闭；恢复连接后才继续办理。要单独演示可退出后使用示例账号与演示密码。独立演示只在本次小程序进程内，复用现有网页的合成工单模型；只模拟模型明确支持的工单动作，不模拟库存写入，也不能替代生产权限、存储、支付和完整PRD验收。项目现有[17组问题](../../../需求/当前问题清单/当前问题清单.md)仍保持原边界。

写入超时、5xx或错误2xx均按“结果暂不确定”处理，不改为演示成功。页面保留原请求正文与幂等键，可按原内容重试；存在未确认提交时，改变正文不能另发一笔。先在业务记录核对后，再使用“已核对，结束重试”解除该意图。明确成功后的另一笔合法操作使用新键；演示操作不会排队补传。

## 五、<span id="development">工程、资源与验证</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

| 位置 | 职责 |
| --- | --- |
| `app.*`、`project.config.json` | 微信原生工程入口和编译配置，未绑定开发机目录 |
| `pages/workbench/index.*` | 登录、工单、详情、表单、库存和设置的WXML／WXSS原生页面 |
| `utils/store.js` | 会话、超时、分页、响应核验、幂等请求、读取顺序与隔离演示 |
| `utils/form.js` | 共享字段转换、金额、日期和实际提交数据 |
| `utils/demo.js` | 从项目现有 `../PC端/Web/维修工作台/data.js` 随包派生，适配为JSON克隆和模块内导出，不依赖浏览器全局；原有业务边界保持不变 |
| `assets/contract.json` | `../后台管理端/共享契约/admin-ui.json` 的包内副本；字段变更需同步并运行副本一致性检查 |
| `assets/RepairLogo.png` | 复用本项目已有 `../PC端/Web/维修工作台/assets/RepairLogo.png`；随包提供，离线保留，无运行时网络图依赖 |

无需npm依赖。从当前微信小程序工程根运行外置专项验证，入口和环境边界见[验证说明](../../../测试/前端/微信小程序/README.md)：

```shell
node --test ../../../测试/前端/微信小程序/mini.test.cjs/mini.test.cjs
```

核心验证使用受控传输替身；配置 `REPAIR_TEST_BASE` 可运行实际隔离Go服务联调。微信开发者工具编译、文件选择器、Canvas触控、手机、体验版本、审核与正式发布分别执行，源码检查和Node运行不代表这些平台项已通过。AppID、主体归属、合法域名、工具及基础库版本按实际项目填写。
