## 二、<span id="pending">待实施的部署能力</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

现有业务源码共用项目内的 [**Go**](https://go.dev/) 服务端，但本系统的运行时准备、环境配置、服务注册、日志及备份接入仍须单独实施和验证。此处没有新造安装、更新、服务注册或防火墙命令，也不能直接把其它系统的启动脚本当作本系统入口。

具体部署前应结合 [项目部署文档](../../../部署文档.md) 核对专用数据目录、密钥、附件、数据库连接、可信访问入口与恢复方法；已有工具或源码不等于已经部署完成。

## 三、<span id="stop">停止、反部署与数据保留</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

当前没有可执行反部署入口；不得把空目录或预留说明当作卸载完成。 后续反部署默认保留业务数据、上传附件、密钥、环境配置、数据库及备份；删除这些内容必须由用户明确选择对应范围，并先核对保留与恢复方式。不能默认删除共享服务、其它项目或整个运行目录。

当前资料没有实现自动反部署或数据删除脚本，详情见 [反部署预留](./undeployment/README.md)。
