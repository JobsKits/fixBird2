本目录保留旧版 `/api/v1` 管理网页，配合 [旧 Go API](../Go服务端/README.md) 的 `cmd/api` 使用。V3.8 当前主页面位于 [维修工作台](../../前端/Web网页/维修工作台/index.html)，使用 `/api/v38`；两者的账号、配置和接口不能混用。目录归入后端仅表示管理职责，不代表新增服务或修复第五轮 17 组问题。

由 [**Go**](https://go.dev/) 服务同源托管于 `/admin/`，无独立构建依赖。未登录时只展示科技感登录入口，包含本地品牌图、CSS 3D 轨道和服务协同示意，支持登录、开户说明和恢复码找回密码；手机优先展示登录表单，减少动画偏好会停止装饰动画。登录成功后页面包括师傅私有图片资料审核、订单与状态、分润结算，以及账务筛选／汇总／CSV导出；手机浏览器采用响应布局，宽表格可横向滚动。

环境常量集中在 `environment.js`：测试头 URL 默认 `http://127.0.0.1:8080`，线上 `production.baseURL` 保留为空。页面提供环境选择器，修改测试地址后点击“保存地址”；接口仍按 `头 URL + /api/v1/...` 拼接。环境与测试地址分别持久化；切换时重置演示数据并忽略旧请求结果。线上未配置时明确显示本地演示，不请求相对地址。正式部署时填写线上 URL，并将 `DEFAULT_API_ENVIRONMENT` 切为注释中保留的 `production`。

从 `http(s)://主机:实际端口/admin/` 打开时，首次默认复用同源测试服务，包括 [**Kubernetes**](https://kubernetes.io/) 的 8081 端口；已保存的有效自定义地址优先。独立静态预览默认使用 8080。无效旧地址自动回退，浏览器禁用存储时仍支持当前页切换。当前服务未开放跨域授权，联网验收请使用 API 同源托管的 `/admin/`；不同端口静态页或 `file://` 打开可以离线演示。

没有已部署服务时，也可以直接打开 `index.html` 查看交互。未登录时保持身份入口；登录后业务模块可先显示本地样例，再并行请求四个后台 API；`API_REQUEST_TIMEOUT_MS` 默认 2 秒，覆盖连接、响应头和完整正文读取。网络失败、坏 JSON、空对象或字段类型错误分别回退，合法的服务端空数组直接显示空态。每个模块明确标记“服务端数据 / 本地演示”，避免部分接口失败时误读。订单、师傅与台账根据 `X-Next-Cursor` 显示“加载更多”入口；刷新重新获取第一页。

模拟收款 / 线下核销仍先请求 API。4xx 拒绝显示 HTTP 状态与业务错误码；超时、断网、5xx 或异常响应提示服务端处理结果尚未确认。失败后只更新独立的本地演示副本，来自服务端的记录使用 `demo-copy-` ID，不污染服务端快照，不自动补发。操作反馈持续显示，后续刷新成功会恢复服务端真实记录；切换环境重置本地演示并忽略旧请求。

演示收款首次创建台账，重复操作不会增加第二条台账，也不会把已经核销的记录改回待核销。金额使用整数分，允许 1 分至 100000000 分；先计算师傅 `floor((金额 × 85 + 50) / 100)`，平台取差额，因此 10 分对应师傅 9 分、平台 1 分，与后端一致。`marketplace-data.js` 集中管理结构校验和本地演示台账。

空列表使用包含 [**iconfont**](https://www.iconfont.cn/) Logo、说明和重试按钮的空态模块。网络图片失败时保留随包的 [RepairLogo.png](./assets/RepairLogo.png)。本目录不包含原生客户端资源工程。

“模拟收款”和“人工核销”只生成模拟账务，不调用支付机构或银行接口。后台业务查询需要后台账号会话，身份审核需要管理员权限，不能用角色头伪造；首次启动自动创建主管理员 `admin / admin`，管理员在设置中新增账号并选择管理员或普通账号权限，见 [旧接口说明](../Go服务端/README.md)；当前 [部署资料](../部署/README.md) 不包含这套旧服务的完整容器／集群部署包。凭据只保留在页面内存，刷新、退出或切换服务地址后重新登录。未登录时业务区域保持隐藏；业务接口失败可在登录后的工作台显示明确标注的本地演示，认证与账号管理操作不模拟成功。

师傅资料默认显示待审核申请，支持状态筛选、加载更多、查看私有图片、填写审核意见并通过／驳回。驳回必填原因；审核携带 expectedRevision，409或网络失败只在独立副本预览，不代表真实审核通过。私有图片带当前Bearer读取，关闭预览、退出或切服务时释放图片并忽略迟到响应。

账务按订单、用户、师傅、类型、渠道、状态和时间筛选，模拟 `simulated` 与真实 `actual` 账本分开。时间范围为开始包含、结束不包含；汇总覆盖全部筛选结果，列表分批加载。汇总是该范围的发生额和借贷净发生额，不代表银行余额，时间筛选不含期初。CSV导出相同筛选范围，最多10000条，超限需缩小查询范围；CSV保留来源标记和关联信息。真实支付未接入，真实账本目前为空；接口失败也不会用模拟账补成真实账。

“设置”提供本人密码修改与恢复码生成；恢复码只显示一次，可下载保存，在忘记密码页使用后失效。管理员可管理全部后台与移动账号、重置任意账号密码及封停／解封；普通账号只能修改自己的密码，看不到且无法调用身份审核与账号管理接口。封停和修改密码撤销旧会话，解封不恢复旧会话。

`auth.js` 管理登录门禁、设置、账号列表、密码和恢复码流程；`auth.css` 管理身份入口视觉；`session.js` 管理后台会话，`operations-data.js` 校验审核和账务结构，`operations.js` 处理业务交互；登录失败、失效会话和旧响应均不伪造服务端确认。聊天仍在下一版本，见[心愿单](../../docs/心愿单.md)。

回归测试使用 [**Node.js**](https://nodejs.org) 内置测试运行器，无需安装包：

```sh
node --test 后端/管理后台页面/tests/*.test.cjs
```

以上命令在项目根目录执行；在本目录执行时改为 `node --test tests/*.test.cjs`。测试覆盖同源端口、存储异常、正文超时、坏响应、空列表、错误反馈、快照隔离、分润、重复核销、分页与环境竞态，以及管理员会话、审核冲突、私有图片、账本隔离与导出。
