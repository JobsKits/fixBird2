## 二、<span id="platforms">平台、部署及数据</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

前端分为 iOS、Android、鸿蒙、微信小程序、Web 网页。桌面副本仅交付网页源码，前四端以 README 预留；原业务仓库的旧客户端没有复制到本次桌面交付。

后端共用一份 [**Go**](https://go.dev/) 源码，管理后台页面单列。各系统资料见 [部署索引](../后端/部署/README.md)：macOS 已有本机前台启动脚本；Linux 四发行版及 Windows 建立专属部署文档、deployment 与 undeployment 预留目录，尚无自动部署／反部署实现。

反部署默认保留业务数据；将来删除必须由运行者明确选择并确认，保留数据时同时保留匹配密钥、附件、配置和必要备份。本次没有运行反部署或移动根 .runtime，第三方 Tools/go 也未移动。
