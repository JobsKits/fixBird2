### 1.5、<span id="flows">业务流程与异常闭环</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

| 流程 | 前置条件与主线 | 异常与终止 |
| --- | --- | --- |
| 寄修／上门维修 | 受理、检测、公司审核报价、客户同单签署、执行、质检、交付、验收、结算、完结 | 拒修、不能修、异议及退款／退件保留责任与余项；上门不套用寄修自动验收 |
| 配件销售 | 报价审核及签署、备货、出库、交付验收、资料票款、完结 | 现款按冻结报价核实净收款；结构化逐项出库校验尚需补齐 |
| 维修预付款 | 仅 `quote.startRequiresPrepayment=true` 时核实约定预付款后开修；缺省 false | 不能仅因填写预付款金额而强制先款；报价变更需形成有效版本并重新确认 |
| 资料／票款 | 明确需求、制作、实际发送；款项人工登记、财务核实、现金交接 | 草稿／上传不代替已制作或已发送；未核实不计实收；退款和红冲重新复核 |
| 完结／重开／返修 | 资料、发票、款项、借还、争议与余项办妥，有权人员确认完结 | 更正触发条件复核；返修开关联子单，原单事实不回退 |

重复操作使用稳定请求键；版本冲突读取新版本后核对，未知写入保留表单与原键。读取失败、空数据和重新加载都有明确入口。服务恢复后采用后续成功响应；演示副本不自动上传正式台账。

### 2.2、<span id="backend">后端、容量与数据库</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>
