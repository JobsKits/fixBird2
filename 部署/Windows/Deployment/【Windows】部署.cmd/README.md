**部署快捷入口：** 可在本系统目录直接双击 [【Windows】双击部署（快捷入口）.cmd](../../【Windows】双击部署（快捷入口）.cmd)；它调用本目录下的规范部署实现，复用同一自述、确认与参数，不另存部署逻辑。

**扫码入口：** 启动后保留各端完整 URL，分别显示用户／工程师工作台和管理端的离线二维码。宽度足够且支持颜色时直接在终端扫码；否则用“打开网页”菜单中的“打开扫码页面”打开本次 HTML，页面内嵌 SVG，并保留 PNG／SVG 文件。回环码明确“仅本机，手机不可用”，公网码使用本轮实际隧道 URL，仍须原有邮箱验证与登录。二维码工具复用已有 Go 和锁定依赖，失败只告警并保留 URL／服务；产物位于本次 Runtime 会话。隧道地址变化会使旧页面失效并生成新码，退出也标记失效；已另存的图片不能撤销，重新部署必须使用新码。来源及参数见[二维码工具](../../../公共组件/地址二维码/README.md)。

## <span id="jobs-toc-heading-1" data-jobs-toc="v2">一、用途与启动</span><!-- jobs-toc:heading-end -->

保留完整项目，双击本目录 [【Windows】部署.cmd](【Windows】部署.cmd)。入口按自身位置调用兄弟包 [【Windows】部署.ps1](../【Windows】部署.ps1/【Windows】部署.ps1)，不复制部署逻辑，不依赖启动目录。路径可含中文或空格，完整工程可以移动。

CMD 以普通用户调用 Windows 自带的 `powershell.exe -NoProfile -ExecutionPolicy Bypass`；执行策略仅对本次 PowerShell 进程生效，不修改系统设置。阅读 PS1 自述后直接回车，缺失 fzf 自动下载并校验，随后在 fzf 选择“本地部署＋内网穿透”或“正常服务器部署”。Esc 取消，本地访问方式子菜单左方向键返回，Ctrl+C 停止本次进程。

## <span id="jobs-toc-heading-2" data-jobs-toc="v2">二、访问范围与资源</span><!-- jobs-toc:heading-end -->

本地模式默认选择“浏览器访问（指定邮箱收验证码）”，允许邮箱可用英文逗号分隔。邮箱只验证公网访问者身份，与维修业务无关；访问者打开HTTPS链接，输入允许的邮箱，再收取并填写验证码。原生 App 不适用浏览器 PIN；公开原生 App 联调必须另选公开模式、使用独立合成资料并准确输入 `PUBLIC`。服务健康和监听 PID 核对通过后才启动隧道，只有本次实际生成的 HTTPS 随机地址才会显示。随后“打开网页”fzf菜单列出公网／本机地址，回车直接交给默认浏览器打开；打开后回到菜单，可反复选择，无需复制或输入网址，终端及服务继续运行。服务器模式列本机地址及扫码页面，回环码明确仅本机。菜单Esc只收起，在原终端按回车再次显示；Ctrl+C停止本次菜单和服务。电脑休眠、关机或网络中断后不能访问，地址可能在下次启动时变化。

服务器模式仅回环监听，当前固定演示账号不能视为生产公网认证。菜单／解析器可按静态锁引导；选择后由PowerShell入口查询官方最新稳定工具，已有工具仅在版本和能力达标时复用，否则校验下载至项目专属机器缓存，不安装系统服务，不改系统 PATH、网络代理或防火墙。仅回收本次进程，不删除业务数据、密钥或备份。

单项目规划下限为 2 核 CPU、4 GiB 可用内存、20 GiB 空闲 SSD；同机运行两个项目建议至少 4 核 CPU、8 GiB 可用内存、40 GiB 空闲 SSD，另留系统资源。Windows x64 可自动准备两种模式的工具；ARM64 可自动准备服务器模式的原生工具，本地穿透需已有健康原生 ARM64 cloudflared，缺失时停止，不混用 x64 包。

## <span id="jobs-toc-heading-3" data-jobs-toc="v2">三、只读审阅与错误</span><!-- jobs-toc:heading-end -->

在本包目录的 PowerShell 终端可执行：

```powershell
& ".\【Windows】部署.cmd" -Check
& ".\【Windows】部署.cmd" -Plan -Mode local
& ".\【Windows】部署.cmd" -Plan -Mode server
```

参数和错误码原样交给 PS1；`-Check` / `-Plan` 不联网、不写配置或日志、不执行工具探针、不启动服务。`-Mode` 仅配合 `-Plan`，不能跳过交互直接公开。无参数启动且失败时 CMD 会暂停显示错误；带参数调用不额外暂停。

缓存、数据目录、邮件 PIN、日志位置、超时变量、故障定位及目标机验收要求见 [完整 PS1 部署说明](../【Windows】部署.ps1/README.md)。本入口当前仅完成静态与隔离验证，Windows 实机原生进程管理和真实公网访问尚需目标机验收。

当前公共工具与运行资料寻址见 [环境说明](../../../README.md#machine-environment)；入口与生命周期见 [本系统代码地图](../../代码地图/README.md)。

本机＋内网穿透属于临时运行：确认公网访问前和公网地址就绪后，运行日志都会醒目显示“关闭此运行终端，服务将结束”。支持颜色的终端使用红色加粗；`NO_COLOR`、`TERM=dumb` 或非交互输出使用纯文本，落盘日志不含颜色控制码。按 `Ctrl+C` 正常停止，业务数据和匹配密钥保留。
